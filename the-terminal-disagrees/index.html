The terminal disagrees

year: 2015
medium: custom computer scripts
dimensions: size variable

[ The terminal disagrees ]

Brief:

[ The terminal disagrees ] is a short script written in Python and Perl that makes the terminal window shake horizontally.

It also changes the background colours repeatedly and shows the text “disagree colours on the screen”, and it can be a metaphor for the political situation.
