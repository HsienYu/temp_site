# We all love Foucault & Deleuze

year: 2015
medium: custom software, projector, computer
dimensions: size variable

\[ We all love Foucault & Deleuze ]

Brief:

\[ We all love Foucault & Deleuze ] is web-crawler software, presented as an installation, that mines how many times people in Taiwan search for the names Foucault & Deleuze on search engines, and it converts that web content into Morse code and represents the pattern of the code as light and beeps.
